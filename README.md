# 开个镖局

一款古代镖局经营模拟游戏。接镖、定路线、配镖师，在山匪、风雪与人情关卡之间经营自己的江湖招牌。

## 在线游玩

https://lynch715.github.io/kaige-biaoju/

## 游戏特色

- 镖单、货值、风险、赔付与镖利构成真实经营闭环
- 武力、侦察、交涉、马术四项能力影响路途抉择
- 五节点真实镖路、20 个动态路遇事件与三档补给方案
- 途中断粮、士气与镖师伤病会延续到后续经营
- 信誉达到 12 后可挑战“龙门盐引”三阶段连续镖
- 镖师成长、地区熟路、设施升级、总号与分号扩张
- 手机与桌面浏览器均可游玩，进度保存在本机浏览器

直接打开 `index.html` 也可离线运行。
