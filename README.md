# 开个镖局

一款古代镖局经营模拟游戏。接镖、定路线、配镖师，在山匪、风雪与人情关卡之间经营自己的江湖招牌。

## 在线游玩

https://lynch715.github.io/kaige-biaoju/

## 游戏特色

- 镖单、货值、风险、赔付与镖利构成真实经营闭环
- 武力、侦察、交涉、马术四项能力影响路途抉择
- 五节点真实镖路、22 个动态路遇事件与三档补给方案
- 途中断粮、士气与镖师伤病会延续到后续经营
- 宿敌系统：结下梁子的匪首会记仇、坐大、反复拦路，可迎战、买路、设伏擒杀，或悬赏剿灭、递帖讲和
- 活的同行：五大镖局名声动态涨落，会抢单、挖角、上门踢馆、送来合镖；年底江湖大会排座次发重赏
- 龙门盐引、寒鸦血书、金銮贡镖三条风格迥异的三阶段传奇连续镖
- 成名之路：办成五件大事（镖行天下、天下第一、富甲一方、金字招牌、快意恩仇）达成大团圆结局
- 镖师成长、地区熟路、设施升级、总号与分号扩张
- 手机与桌面浏览器均可游玩，进度保存在本机浏览器（旧存档自动升级）

直接打开 `index.html` 也可离线运行。
